# Commercial Use

This page explains when you need a separate commercial agreement for OpenCompany.

The source code is licensed under [BSL 1.1](LICENSE.md), but the Additional Use Grant only covers a specific set of production uses.

## Allowed without a separate commercial agreement

The following are intended to be allowed under the Additional Use Grant:

- self-hosting OpenCompany for your own internal business operations
- internal use by affiliated entities in the same corporate group
- consultant, contractor, or MSP setup and operation for one customer's internal use
- implementation, support, and maintenance services for a single customer's internal deployment

## Uses that require a separate commercial agreement

The following uses are outside the Additional Use Grant:

- running OpenCompany as a generally available hosted service
- multi-tenant hosted offerings for multiple customers
- white-labeling OpenCompany as your own platform
- embedding or OEM commercialization where the value derives substantially from OpenCompany
- premium or plan-gated feature activation that requires a commercial agreement and license key

## Premium features and license keys

Some premium capabilities may be visible in the source tree but still require:

- a commercial agreement
- a valid license key
- a paid plan or specific entitlements

Source availability does not itself grant those production rights.

## If you are unsure

The simplest test is:

If OpenCompany is being used only for one organization's own internal operations, you are likely inside the Additional Use Grant.

If you are commercializing OpenCompany itself as a product, platform, or hosted service for third parties, you likely need a separate commercial agreement.
