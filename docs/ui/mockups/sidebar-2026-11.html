Home is the attention pageApprovals, questions, takeovers and sign-in requests rank first ("3 need you"), then results, then FYI. It replaces Dashboard, Activity and Workload, and the daily brief lands here. It isn't called "Inbox", so it doesn't get confused with the Mail app or agents' own inboxes.
PinnedPins are per person and can be any thread, table, issue or doc. Pinning is the only way an object appears at the top level of the rail.
Agents are teammatesClicking an agent opens a DM with it, not its profile. The status dot shows working (with the current task), needs you (!), idle or paused. 🖥 means the agent has its own computer; Cleo is VFS-only. The rail shows about 5 recent agents, and the rest are in Team or ⌘K.
People, groups, channelsThese work like a normal messenger, with presence, unread counts and mentions. A group chat can mix agents and people.
AppsOptional add-ons such as Mail, CRM, Calendar and Helpdesk, built only from the core primitives.
Spaces are flat, with fixed toolsEvery Space has the same six tools (Issues, Tables, Docs, Files, Artifacts, Routines), plus scoped views from installed apps, such as Deals here. Spaces don't nest inside each other and there are no pages inside pages.
FooterTeam is the directory of people and agents, and holds agent profiles. Admin holds connections, policies, members and billing.
MobileA bottom bar with Home · Chats · Spaces · Team. Cards open as full-screen sheets.
