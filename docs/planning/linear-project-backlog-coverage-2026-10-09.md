## Authority and scope

The app repository owns implementation truth (`docs/CURRENT_STATE.md`) and priority (`docs/ROADMAP.md`). Linear owns operational tracking. Active remaining requirements were grouped into delivery-sized issues with source paths and acceptance checklists; related small requirements are subcriteria, not duplicate issues. The source inventory covers repository Markdown outside dependencies, ignored inspiration/temp/build artifacts, plus vault TODO/planning/testing files. Private commercial strategy is not copied.

Old unchecked boxes are not evidence that a feature is missing. Implemented baselines remain implemented references; stale schema/package/UI assumptions are replaced by current contracts. User-selected mruby-only Code Mode supersedes new Lua/QuickJS work. Complete self-hosted security is not privately gated by obsolete enterprise-edition sketches. Bowerbird core work remains in its own project; this project covers only the optional app-side connector. KosmoKrator imported docs remain explicitly out of project scope.
